1. Spectral indices and their value ranges

Each spectral index has a characteristic range of values. Knowing the expected range helps you set visualization parameters and spot errors.

IndexFull nameTypical range
NDWINormalized Difference Water Index−1 to +1
NDSINormalized Difference Snow Index−1 to +1
SAVISoil Adjusted Vegetation Index−1 to +1
AVIAdvanced Vegetation Index0.00 to 114.98
EVIEnhanced Vegetation Index−1 to +1
DVIDifference Vegetation Index−1 to +1
Watch out

AVI is the odd one out — it is an unbounded ratio-type index with values well above 1. Do not apply a −1 to +1 palette to it.

2. Exporting single images to Google Drive

To download an image, export it from Earth Engine to your Google Drive, then download it from Drive.

Code — export an image

Export.image.toDrive({
  image: image,
  description: ‘exportImageToDrive’,
  scale: 10,
  region: geometry,
  maxPixels: 1e13
});

  • Set scale to the resolution you need (e.g. 10 m for Sentinel-2).
  • Set region to the area of interest.
  • Increase maxPixels if the export fails with a pixel-count error.
  • Find the exported file in your Google Drive under Earth Engine Exports.

4. Band combinations

Different band combinations highlight different features. For Sentinel-2:

CombinationBandsUse
True colorB4, B3, B2Natural appearance
Color infraredB8, B4, B3Vegetation appears red
Shortwave infraredB12, B8, B4Bare soil, geology, fire scars

In the Code Editor, set the visualization parameters with {bands: […], min: …, max: …} when adding the layer to the map.

5. Mosaicing all indices into one image

Instead of keeping each index as a separate layer, combine them into a single multi-band image:

Code — mosaic indices

var indices = NDVI.addBands(NDWI).addBands(NDSI).addBands(SAVI).addBands(AVI).addBands(EVI).addBands(DVI);
Map.addLayer(indices, {bands: [‘NDVI’, ‘NDWI’, ‘NDSI’], min: -1, max: 1}, ‘Indices’);

Now one image holds all indices, and you can export it once instead of six times.

6. Extracting index values at GPS points

To get index values at your field GPS points:

  1. Import your GPS points as a CSV (with latitude/longitude columns) via the Assets tab or a FeatureCollection from a table.
  2. Use sampleRegions() to extract the index values at each point:
Code — extract at points

var extracted = indices.sampleRegions({
  collection: gpsPoints,
  properties: [‘NDVI’, ‘NDWI’, ‘NDSI’, ‘SAVI’, ‘AVI’, ‘EVI’, ‘DVI’],
  scale: 10
});
Export.table.toDrive({collection: extracted, description: ‘indices_at_gps_points’, fileFormat: ‘CSV’});

The exported CSV contains one row per GPS point with the index values — ready for analysis in Excel or R.

7. Zonal statistics for groundwater storage

To summarize index values within zones (e.g. administrative boundaries or aquifer polygons), use a reducer over the region:

Code — zonal statistics

var stats = indices.reduceRegions({
  collection: zones,
  reducer: ee.Reducer.mean(),
  scale: 10
});

Zonal statistics of indices such as NDWI and NDVI over time are used to study groundwater storage dynamics — vegetation and water stress respond to changes in subsurface water availability.
