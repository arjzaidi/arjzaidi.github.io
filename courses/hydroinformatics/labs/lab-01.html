1. What is Google Earth Engine?

Definition

Google Earth Engine (GEE) is a cloud-based platform for planetary-scale geospatial analysis.

  • No more downloading and analyzing individual tiles one at a time — the data and the computing power are both in the cloud.
  • Earth Engine provides an API to process, analyze and visualize the data using Google’s machines.
  • Data storage and processing are all performed at Google.
  • “Whatever USGS has, Earth Engine has” — and much more.
  • All you need to use Earth Engine is an internet connection.

Google’s mission: “To organize the world’s information and make it universally accessible and useful.”

2. Signing up and accessing the Code Editor

  1. Register for an Earth Engine account: https://signup.earthengine.google.com/
  2. Once registered, access the Code Editor at: https://code.earthengine.google.com
  3. The Code Editor uses the JavaScript programming language.
  4. For a JavaScript background: https://developers.google.com/earth-engine/tutorial_js_01
Note

Earth Engine access is granted per account and can take a little time to activate. Sign up early — do not wait until the lab session.

3. The Earth Engine Data Catalog

The Data Catalog is the collection of datasets available in Earth Engine: https://developers.google.com/earth-engine/datasets/

StatisticValue
Public datasetsThousands (as of 2020)
New images addedThousands every day
Total stored dataOver 90 petabytes (PB) and expanding rapidly
Growth rateRoughly 1 PB of new data every month
Historical spanOver 50 years of continuous global satellite records
Ingestion latencyOne or two days between scene acquisition and catalog availability

By the numbers: 33 years of satellite data, over 5,000,000 Landsat and Sentinel scenes analyzed, and 3 quadrillion pixels (3,000,000,000,000,000).

4. The Code Editor interface and your first script

The Code Editor has three main areas: the search bar (top), the script panel (left) and the map (right).

Your first script

Code

print(‘Hello, I am [your name]’);

Type the line above into the script panel and click Run. The output appears in the Console tab. Then use the Clear Script button to start fresh.

6. Global composites with a few lines of code

One of the most powerful ideas in Earth Engine: a global mosaic from thousands of scenes in a few lines of code.

Code — Landsat global composite

var composite = ee.Algorithms.Landsat.simpleComposite({
  collection: ee.ImageCollection(‘LANDSAT/LC08/C01/T1’),
  asFloat: true
});
Map.addLayer(composite, {bands: [‘B4’, ‘B3’, ‘B2’], max: 0.3}, ‘composite’);

Reference script: https://code.earthengine.google.com/05d2e23206b329dfe696e5ba8e232c3f

Related reading: Google Earth Engine: Planetary-scale geospatial analysis for everyone (Gorelick et al., 2017)

7. Searching, visualizing and saving your work

Search the Data Catalog

  1. Type keywords (e.g. elevation) in the search window.
  2. Select a dataset from the results, or view it in the Catalog page.
  3. Click Import to add it to your script, or open the Code Editor to explore it.

Visualize

  • Change layer transparency with the layer slider.
  • Change the symbology color to suit your map.

Save your script

  • Click Save and give your script a meaningful name (e.g. Lab1_elevation).
  • Scripts are stored in your account — you can reopen them from the Scripts tab.

Lab Work

Complete the following steps:

  1. Sign up for a Google Earth Engine account (if you have not already) and open the Code Editor.
  2. Run your first script: print “Hello, I am [your name]”.
  3. Search the Data Catalog for SRTM elevation data and add it to the map.
  4. Change the layer transparency and the symbology color of the elevation layer.
  5. Save your script with a meaningful name.
