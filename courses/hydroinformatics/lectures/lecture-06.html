In this lecture

This is a guest lecture by Ms. Rubab (IWRM), USPCAS-W, Mehran University of Engineering & Technology, Jamshoro. It introduces the foundations of artificial intelligence and its two most important subfields for water data analysis.

  1. Artificial Intelligence — what it is and everyday examples
  2. Machine Learning — learning from data without explicit programming
  3. Deep Learning — neural networks with many layers
  4. AI vs. ML vs. DL — the “brain” analogy
  5. Types of Machine Learning — supervised, unsupervised and reinforcement
  6. Common ML algorithms — regression, classification, clustering, dimensionality reduction
  7. Types of Deep Learning — ANN, CNN, RNN and LSTM

1. Artificial Intelligence

Definition

Artificial Intelligence (AI) is the field of creating computer systems that can perform tasks requiring human-like abilities such as learning, reasoning, perception, and decision-making.

You already use AI every day, often without noticing it:

Everyday exampleHow AI works behind the scenes
Google MapsAI combines live traffic data with route prediction to suggest the best route.
Face unlockThe camera captures your face, AI performs face recognition, and the phone unlocks.

2. Machine Learning

Definition

Machine Learning (ML) is a type of AI that allows computers to learn from data and make predictions or decisions without being directly programmed for every task.

Instead of writing explicit rules for every situation, the computer finds the patterns itself:

  • Recommending shows based on what you watch.
  • Online shopping sites showing you products you might like.

3. Deep Learning

Definition

Deep Learning (DL) is a type of Machine Learning that uses neural networks with multiple layers to learn complex patterns from large amounts of data.

Deep learning shines when the data is large and the patterns are complex — for example, an image goes into a deep learning model and comes out as a recognized face.

4. AI vs. ML vs. DL

A simple way to keep the three apart is the “brain” analogy:

ConceptAnalogy
AIThe whole brain — the entire field of creating intelligent systems.
Machine LearningTeaching the brain to learn from experience.
Deep LearningTeaching the brain by showing it lots and lots of examples.

In other words: Deep Learning is a subset of Machine Learning, and Machine Learning is a subset of Artificial Intelligence.

5. Types of Machine Learning

Machine learning is commonly divided into three types, depending on how the model learns:

TypeHow it learnsTypical tasks
Supervised LearningLearns from labeled dataRegression, classification
Unsupervised LearningFinds hidden patterns or groups in dataClustering, dimensionality reduction
Reinforcement LearningLearns through trial and error to maximize rewardDecision-making agents

5.1 Supervised Learning

In supervised learning, the model learns from labeled data — examples that already have the correct answer attached.

Water example

Predicting river stage from temperature, rainfall, soil moisture and evaporation.

Supervised learning covers two kinds of tasks:

TaskWhat it predictsExample
RegressionA continuous numerical valuePredicting river stage = 5.8 m
ClassificationA category or classFlood risk = Low, Medium or High

5.2 Supervised Learning: common algorithms

AlgorithmWhat it does
Linear RegressionPredicts numerical values
Logistic RegressionPredicts categories
Decision TreeMakes decisions using a tree structure
Random ForestUses many decision trees together
KNN (K-Nearest Neighbors)Predicts using similar data points
SVM (Support Vector Machine)Separates data into classes

5.3 Unsupervised Learning

In unsupervised learning, the model finds hidden patterns or groups in data — there are no predefined labels to learn from.

Water example

Grouping areas based on similar rainfall or temperature patterns.

Unsupervised learning covers two kinds of tasks:

TaskWhat it doesExample
ClusteringGroups similar data points together without predefined labelsGrouping areas with similar rainfall patterns
Dimensionality ReductionReduces the number of variables while keeping the most important informationReducing 20 climate variables to 3 important ones

5.4 Unsupervised Learning: common algorithms

AlgorithmWhat it does
K-Means ClusteringGroups similar data
Hierarchical ClusteringCreates groups in a hierarchy
DBSCANFinds natural groups and unusual points
PCA (Principal Component Analysis)Reduces many variables into fewer important variables
Water example

Rainfall + temperature + soil moisture → ML → similar climate groups.

5.5 Reinforcement Learning

Definition

Reinforcement learning is a branch of machine learning in which an AI agent learns to make optimal decisions through trial and error to maximize cumulative reward.

The agent is rewarded for good actions and penalized for bad ones:

  • Correctly stops at a red light → reward.
  • Makes a wrong move → penalty.

5.6 Reinforcement Learning: common algorithms

AlgorithmWhat it does
Q-LearningLearns the best action through rewards
SARSALearns from actions and their rewards
DQN (Deep Q-Network)Uses deep learning for decision-making
Example

Robot → action → reward / penalty → learns the best action.

6. Types of Deep Learning

Deep learning architectures are specialized for different kinds of data:

ArchitectureWhat it learnsExample
ANN — Artificial Neural NetworkLearns patterns from data to make predictionsPredicting house prices from area, number of rooms and location
CNN — Convolutional Neural NetworkLearns from images and recognizes objects or patternsIdentifying whether an image contains a cat or a dog
RNN — Recurrent Neural NetworkLearns from data that comes in sequencePredicting tomorrow’s temperature using previous days’ temperatures
LSTM — Long Short-Term MemoryLearns from sequences while remembering important past informationPredicting river stage using previous river stages, rainfall, temperature and soil moisture

Which model for which problem?

Classroom activity

For each water problem below, name the ML or DL approach you would reach for first.

1. You want to predict river stage (a continuous value) from temperature, rainfall, soil moisture and evaporation.

Supervised learning — regression (e.g. linear regression or a neural network), because the target is a continuous numerical value.

2. You want to label flood risk as Low, Medium or High from historical records.

Supervised learning — classification (e.g. logistic regression, decision tree, random forest, KNN or SVM), because the target is a category.

3. You want to group areas with similar rainfall and temperature patterns, with no predefined labels.

Unsupervised learning — clustering (e.g. K-Means, hierarchical clustering or DBSCAN).

4. You have 20 climate variables and want to keep only the 3 most important ones.

Dimensionality reduction — e.g. PCA (Principal Component Analysis).

5. You want to predict tomorrow’s temperature from the previous days’ temperatures.

RNN — recurrent neural networks learn from sequential data.

6. You want to predict river stage using previous river stages, rainfall, temperature and soil moisture, remembering important past information.

LSTM — Long Short-Term Memory networks learn from sequences while remembering important past information.

Key takeaways

  • AI is the field of creating computer systems that perform tasks requiring human-like abilities — learning, reasoning, perception and decision-making.
  • Machine Learning is a type of AI that learns from data without being programmed for every task; Deep Learning is a type of ML that uses multi-layer neural networks on large datasets.
  • Remember the analogy: AI = whole brain, ML = teaching the brain from experience, DL = teaching the brain with lots of examples.
  • Three types of ML: supervised (labeled data — regression, classification), unsupervised (hidden patterns — clustering, dimensionality reduction) and reinforcement (trial and error with rewards and penalties).
  • Four DL architectures: ANN (general predictions), CNN (images), RNN (sequences) and LSTM (sequences with memory).
  • Water applications run through the whole stack: river stage prediction (regression), flood risk (classification), climate grouping (clustering) and streamflow forecasting (LSTM).
